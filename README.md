# BZO Concept – Downloads

Firmware, TunerStudio files, datasheets and tools for **BZO Concept** programmable ECUs and accessories.
This repository mirrors the *Téléchargements* section of [bzo-concept.fr](https://www.bzo-concept.fr/telechargements/).

Shop: [bzo-concept.fr/boutique](https://www.bzo-concept.fr/boutique/)

## ECUs (Speeduino based, STM32F4)

| Folder | Content |
|---|---|
| [Essential_v1.2](Essential_v1.2) | Firmware, TunerStudio `.ini`, base tune, datasheet |
| [Double_Eight](Double_Eight) | Firmware, TunerStudio `.ini`, base tune, datasheet (FR / EN) |
| [CoreF4_CoreF4_Boxed](CoreF4_CoreF4_Boxed) | Firmware packs `v1.2` and `2025.01.6`, `.ini`, base tunes, pinout, datasheet |
| [SmartBoard_v1.2](SmartBoard_v1.2) | Firmware (UART / USB) and integration kit: KiCad symbol, footprint, 3D model, pinout, typical application |
